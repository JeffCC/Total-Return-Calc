台股總報酬比較 ─ 使用說明
==================================================

這是什麼？
  計算台股上市、上櫃股票與 ETF 在指定期間的「含息總報酬」(含現金股利、
  股票股利、現金增資、分割、減資)，可同時比較最多 10 檔，並畫出走勢圖。
  查詢時才即時下載該檔資料，通常 1~3 秒完成。


★ 不想安裝？直接用網頁版 (電腦、手機都可以)：
    https://jeffcc.github.io/Total-Return-Calc/
  網頁版的查詢歷史只存在自己的瀏覽器裡；免費額度用完時會提示，
  等約一小時後再查即可。以下為「本機版」安裝方式。


一、安裝 (只需做一次)
--------------------------------------------------
1. 安裝 Python (免費)
   到 https://www.python.org/downloads/ 下載並安裝 Python 3.9 以上版本。

   ★ Windows 安裝時，第一個畫面最下方務必勾選
     「Add python.exe to PATH」，再按 Install Now。
     (沒勾到的話，請重新執行安裝程式 → Modify → 勾選後重裝)

2. 把收到的程式資料夾 (zip 解壓縮後) 放在任意位置，例如桌面。
   ※ 請先「解壓縮」再執行，不要直接在 zip 裡面點開。

3. 需要的套件 (requests) 第一次啟動時會自動安裝，不用另外處理。


二、啟動
--------------------------------------------------
Windows：
  雙擊 start.bat
  → 會出現黑色視窗，並自動開啟瀏覽器 (http://localhost:8893/)
  → 使用期間「不要關閉黑色視窗」；用完直接關掉黑色視窗即可結束。

  若跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
  若瀏覽器沒有自動開啟：看黑色視窗上顯示的網址，手動貼到瀏覽器。

Mac：(第一次)
  1. 安裝 Python：到 https://www.python.org/downloads/ 按黃色
     「Download Python 3.x.x」，下載 .pkg 後雙擊，一路「繼續」安裝完成。
  2. 解壓縮：在「下載項目」雙擊 zip，會出現程式資料夾
     (可先把它拖到「文件」或桌面)。
  3. 開終端機：按 command + 空白鍵，輸入 terminal (或「終端機」)，按 return。
  4. 進到資料夾：在終端機輸入 cd 加一個空白 (先不要按 return)，
     再從 Finder 把程式資料夾「拖進」終端機視窗，路徑會自動填上，然後按 return。
  5. 安裝套件 (只需一次)，輸入後按 return：
         python3 -m pip install requests
  6. 啟動，輸入後按 return，瀏覽器會自動開啟：
         python3 server.py
  使用期間不要關閉終端機；結束時在終端機按 control + C，或直接關閉視窗。

Mac：(之後每次) 重複步驟 3、4、6 即可。

Mac：(選用) 改成雙擊啟動
  在步驟 4 之後輸入：  chmod +x start_mac.command
  之後在 Finder 對 start_mac.command「按右鍵 → 打開 → 打開」(第一次要這樣)，
  以後直接雙擊即可。

※ 必須用上述方式啟動。直接雙擊 index.html 是無法使用的。


三、怎麼用
--------------------------------------------------
1. 在「標的」輸入代碼或名稱 (例：2330、台積電、00878)，按 Enter 加入。
   可一次輸入多檔，用 , 或空格分隔，例：2330,0056 00878 按 Enter。
   已加入的標的可用滑鼠拖拉調整順序 (手機上長按再拖)，
   再按「查詢」，圖表與表格就依你排的順序顯示。
2. 可勾選基準：0050、IR0001 (加權報酬指數，已含息)。
3. 選區間：1M / 3M / 6M / YTD / 1Y / 3Y / 5Y / 10Y，或自訂日期後按「自訂」。
4. 按「查詢」。
5. 結果表格：點欄位標題可排序 (▼由大到小 / ▲由小到大 / 再點恢復)。
   「區間除權息」滑鼠移上去可看每次配息金額。
   報酬率顏色：紅色為漲、綠色為跌 (台灣習慣)。
   黃底列 = 該檔在區間內才上市，起點較晚。
6. 查詢歷史 (頁面下方)：每次查詢自動記錄
   ★ 釘選：常用組合 (例如自己的庫存) 固定在最上方，下次開啟自動查詢
   命名：幫組合取名字
   重新查詢：以今天為終點重新計算


四、使用需知
--------------------------------------------------
‧ 需要網路。資料來源為 FinMind 公開資料 (失敗時改用證交所 / 櫃買中心)。
‧ 當天收盤資料約下午 3 點後才會有；之前查詢的終點會是前一個交易日。
‧ 免費資料額度：每小時約 300 次 API 呼叫。一檔「第一次」查詢約用 4 次，
  之後只補新日期，一般使用不會超過。若出現「FinMind 錯誤 (402)」或
  「上限」字樣，表示額度用完，等一小時後再查即可。
  常大量查詢者，可到 https://finmindtrade.com/ 免費註冊取得 token，
  存成文字檔 userdata\finmind_token.txt (只放 token 一行) 即可提高額度。
‧ 程式只在自己電腦上執行 (localhost)，不會上傳任何資料；
  查詢歷史存在 userdata\history.json，下載的資料快取在 userdata\cache\。
  想清除紀錄，關閉程式後刪除 userdata 資料夾即可。
‧ 含息報酬採「股利全數再投入、現增全數認購」的理論值，
  未計手續費、交易稅、股利所得稅與二代健保補充保費，
  實際報酬會略低。結果僅供參考，不構成投資建議。
‧ 少數特殊事件 (資料源缺漏的分割等) 可手動補在 data\manual_events.json。


五、常見問題
--------------------------------------------------
Q: 雙擊 start.bat 出現 "Python not found"
A: Python 沒安裝或安裝時沒勾 Add to PATH，請見「一、安裝」。

Q: 出現 pip / requests 安裝失敗
A: 確認網路正常後再執行一次；或開「命令提示字元」輸入
   python -m pip install requests

Q: 黑色視窗一閃就關掉
A: 請確認是先解壓縮後才執行，且資料夾內檔案都在 (scripts、js、css 等)。

Q: 查不到某檔
A: 確認代碼正確；興櫃股票不支援。剛上市的標的需等有交易資料。
